## Product Description

Rekonvia is an AI renewal workspace for commercial insurance brokers in Indonesia, starting with multi-location Property All Risks accounts.

Brokers currently rebuild each renewal by hand using last year’s Word quotation, Excel location lists, and client messages. Rekonvia compares prior and proposed data, traces each client confirmation to its source, and flags discrepancies such as unclear addresses.

Once details are confirmed and reviewed, it exports an editable Word quotation with original clauses preserved and amendments listed separately. The initial prototype is in development and being tested on a fictional case; file import comes next.
